# Flat 501 reference viewer modules

Focused static copies of the Flat 501 model source from:
- Repository: https://github.com/shivakandula456-tech/flat
- Source commit: 74ca0000fcc5244566e2400dfa64fc897a51ac4e

Included only: the apartment 3D viewer, property layout, procedural model/material builders, and their utility modules. The unrelated Flat website pages are not included.

Three.js and OrbitControls are reused from the existing IRIS site and import map. The original Flat 501 video and poster remain separately loaded media assets from the pinned source revision.

The upstream source describes all interior geometry and dimensions as provisional visual estimates from a walkthrough, not a surveyed architectural plan.
